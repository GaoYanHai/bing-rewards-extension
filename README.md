# Bing 积分助手

面向 Edge / Chrome 的 Manifest V3 扩展。帮你在浏览器开着的时候完成今天的 Bing 搜索，并随时看清进度。

对外名称：Bing 积分助手（Bing Rewards Assistant）

当前版本：2.2.0

## 功能

- 工具栏正式图标、徽章和 Popup，不必先打开 Bing
- 查看今日电脑搜索和每日活动进度，开始 / 暂停 / 继续 / 停止今天的任务
- 未登录时会停下来，并提示去登录
- 每日活动先识别再执行，高风险卡片默认跳过
- 可查看今日运行日志，失败时能看出原因
- 支持自定义搜索词、换一批和拉黑
- 首次使用会看到风险说明
- 设置每天自动开始时间后，立刻显示下次执行时间
- 完成或失败时发送通知，并更新徽章
- 默认安全模式：只做搜索，不点击每日活动
- Bing 搜索页只保留迷你状态条，设置都在选项页
- 浏览器运行时按设定时间自动启动，错过当天时间会补做
- Popup 显示近 7 天完成情况，以及已连续完成几天
- 昨天计划日还没做完时会提醒；失败后可从今天的进度接着做
- 周末可单独设置更保守的目标，默认仍与工作日相同
- 危险设置默认关闭，确认后才能逐项打开
- Popup 底部固定「设置 / 打开 Bing / 说明」，说明是独立页面
- 搜索页展开后可换一批、拉黑当前词，不再放设置入口
- 选项页可导出 / 导入本机设置和词库
- 打开过 Rewards 后，会尽量显示电脑搜索、移动搜索和每日活动的剩余
- 移动搜索只提醒，不会自动执行

## 安装

1. 打开 Edge 的 `edge://extensions/` 或 Chrome 的 `chrome://extensions/`。
2. 打开“开发人员模式”。
3. 选择“加载解压缩的扩展”，然后选择本目录。
4. 点击工具栏图标，阅读风险说明后开始使用。
5. 登录微软账号，再点“开始今日任务”。

## 使用

- 日常操作都在 Popup：看进度、开始、暂停、继续、停止、查看下次定时。
- 点“设置”打开选项页，可改今日目标、周末目标、搜索次数、自动开始时间、重复规则、词库和通知。
- 可导入自己的搜索词，换一批，或拉黑某个词。
- Bing 页面上的迷你条只显示现场状态；展开后可换一批搜索词、查看任务摘要和最近日志。
- 浏览器开着时，到点会自动开始。当时没开，下次打开浏览器会补做今天。
- 电脑关机或睡眠时，扩展无法自己开机。

## 权限

- `alarms`：保存每日后台闹钟。
- `storage`：保存设置、进度和运行状态。
- `tabs`：打开或唤醒 Bing 搜索标签页。
- `notifications`：完成或失败时提醒你。
- `https://*.bing.com/*`：在 Bing 搜索和 Rewards 页面运行内容脚本。

## 注意

自动搜索和自动点击可能不符合 Microsoft Rewards 使用规则，存在积分无效或账号受限的风险。请自行判断并承担使用后果。

## 商店简介

帮你在浏览器开着的时候完成今天的 Bing 电脑搜索，并看清还剩多少。默认只做搜索，不点击高风险活动，也不会改装成手机搜索。

权限用途见上方「权限」。自动搜索可能不符合 Microsoft Rewards 使用规则，请自行判断。
