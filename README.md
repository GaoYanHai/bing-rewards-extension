# Bing 积分助手

面向 Edge / Chrome 的 Manifest V3 扩展。帮你在浏览器开着的时候完成今天的 Bing 搜索，并随时看清进度。

对外名称：Bing 积分助手（Bing Rewards Assistant）

当前版本：1.3.0

## 功能

- 工具栏正式图标、徽章和 Popup，不必先打开 Bing
- 查看今日电脑搜索和每日活动进度，开始 / 暂停 / 继续 / 停止今天的任务
- 未登录时会停下来，并提示去登录
- 每日活动先识别再执行，高风险卡片默认跳过
- 可查看今日运行日志，失败时能看出原因
- 支持自定义搜索词、换一批和拉黑
- 首次使用会看到风险说明
- 设置每天自动开始时间后，立刻显示下次执行时间
- 完成或失败时发送通知，并更新徽章
- 默认安全模式：只做搜索，不点击每日活动
- Bing 搜索页只保留迷你状态条，设置都在选项页
- 浏览器运行时按设定时间自动启动，错过当天时间会补做

## 安装

1. 打开 Edge 的 `edge://extensions/` 或 Chrome 的 `chrome://extensions/`。
2. 打开“开发人员模式”。
3. 选择“加载解压缩的扩展”，然后选择本目录。
4. 点击工具栏图标，阅读风险说明后开始使用。
5. 登录微软账号，再点“开始今日任务”。

## 使用

- 日常操作都在 Popup：看进度、开始、暂停、继续、停止、查看下次定时。
- 点“设置”打开选项页，可改今日目标、搜索次数、自动开始时间、重复规则、词库和通知。
- 可导入自己的搜索词，换一批，或拉黑某个词。
- Bing 页面上的迷你条只显示现场状态；展开后可换一批搜索词、查看任务摘要和最近日志。
- 浏览器开着时，到点会自动开始。当时没开，下次打开浏览器会补做今天。
- 电脑关机或睡眠时，扩展无法自己开机。

## 权限

- `alarms`：保存每日后台闹钟。
- `storage`：保存设置、进度和运行状态。
- `tabs`：打开或唤醒 Bing 搜索标签页。
- `notifications`：完成或失败时提醒你。
- `https://*.bing.com/*`：在 Bing 搜索和 Rewards 页面运行内容脚本。

## 注意

自动搜索和自动点击可能不符合 Microsoft Rewards 使用规则，存在积分无效或账号受限的风险。请自行判断并承担使用后果。

## 更新日志

### 1.3.0 - 2026-08-28

更像人版。把“跑起来”做成“像人在用，停下来有小结”。

- 搜索间隔可在选项里调整，默认仍是 8-14 秒，不能短于 8 秒
- 可打开模拟输入：在搜索框里逐字输入再搜索，找不到搜索框时才跳转链接
- 运行中可以暂停和继续，暂停后进度还在；停止仍会结束本次运行
- 测验 / 投票在“尽量全做”时会停下来，可选择“我点完了”或“跳过这张”
- 完成态展示今日小结：搜索次数、每日活动结果、用时；能读到积分时显示今日新增
- 完成通知改成小结，不再只报一个数字
- 定时可设每天 / 工作日 / 周末，Popup 仍显示下次时间
- 全屏或正在打字时会先暂停，条件消失后自动继续
- 默认仍然是安全模式，只做电脑搜索

### 1.2.0 - 2026-08-28

懂业务版。把自动搜索器升级成今日积分方案。

- 未登录时不再空转；运行中掉登录会立刻停止，并提示去登录
- 每日活动改为任务清单：可自动完成 / 需要你点一下 / 已完成 / 已跳过
- 今日目标三档：只搜满、搜满 + 安全任务、尽量全做。默认仍是安全模式
- 先完成电脑搜索，再处理安全的每日活动；高风险卡片默认跳过
- 测验和投票不会假装全自动，只会提醒你点一下
- Popup 分别显示电脑搜索和每日活动进度
- 新增可查看的今日运行日志，失败原因改成分类后的人话，并告诉下一步
- 支持导入自定义搜索词、查看今日词库、换一批和拉黑
- 选项里可选择补做前先问一声；移动搜索只展示配额，默认不执行

### 1.1.0 - 2026-08-28

体面版。把执行能力留在后台，把今日状态放到图标和 Popup 上。

- 新增工具栏正式图标、Popup 和选项页
- 不在 Bing 页面也能查看今日进度，并开始 / 停止任务
- 首次使用增加风险说明，需确认后才能开始
- 设置自动开始时间后立即生效，并显示下次执行时间
- 完成或失败时发送桌面通知，工具栏徽章同步变化
- 默认开启安全模式：只做电脑搜索，不自动点击每日活动
- 搜索页改为迷你状态条，专家参数移到选项页
- 去掉名不副实的热榜名称和推广外链
- 状态文案改为普通人能看懂的说明，并修正错别字
- 默认电脑搜索目标调整为 30 次，词库改为日常短词 / 生活长尾

### 1.0.0 - 2026-08-25

首个可用版本，由油猴脚本改造为 Manifest V3 扩展。

- Bing 搜索页悬浮控制面板
- 按积分变化判断有效搜索
- 可选 Rewards 每日任务处理
- 每日定时启动，以及错过时间后的补执行
- 多标签页执行互斥
- 深色模式和悬浮窗位置记忆
