# Bing 积分助手

面向 Edge / Chrome 的 Manifest V3 扩展，提供 Bing 搜索、每日活动辅助、定时执行和本机进度记录。当前源码版本 **3.4.4**；商店版本取决于审核进度。

[English documentation](README.en.md) · 中文界面与英语界面均可使用。在“设置 → 基础设置 → 界面语言”选择跟随浏览器、简体中文或 English；浏览器中文环境默认中文，其他环境默认英语。搜索词不会随界面语言被翻译。

[Edge 商店安装](https://microsoftedge.microsoft.com/addons/detail/bblfidpemgicndppkjeihkldadnllgjj) · [更新日志](CHANGELOG.md) · [隐私说明](PRIVACY.md)

## 安装与使用

推荐从 Edge 商店安装。开发版可克隆本仓库，在 `edge://extensions/` 或 `chrome://extensions/` 打开开发人员模式，选择“加载解压缩的扩展”，加载本目录。替换源码后须在扩展管理页点击重新加载，并刷新已经打开的 Bing 页面。

1. 点击工具栏图标，阅读并确认使用说明。
2. 打开 Bing，登录微软账号，再点击“开始今日任务”。
3. Popup 可查看进度、暂停、继续、停止及近期记录；“设置”中调整搜索目标、间隔、词库和定时。
4. 默认只做电脑搜索。每日活动取决于目标设置；移动搜索、测验辅助需在危险设置中另行启用。

首次手动开始会遵守设置的目标次数。当天已完成后，主动再点开始会继续搜索，直到连续不加分或手动停止。暂停保留进度，停止结束当前运行，之后可从当天进度重新开始。

## 功能与实际限制

| 功能 | 行为与限制 |
| --- | --- |
| 中英文界面 | 设置页、弹窗、Bing 状态条、系统通知及导出日志跟随语言选择；切换语言保留现有设置和记录。内置搜索词包仍保留原词，可输入英语自定义词。 |
| 搜索与积分 | 读取页面积分变化记录有效搜索。默认间隔 8–14 秒，最短 8 秒；本地计数不是微软配额证明。 |
| 暂停与继续 | 支持主动暂停，以及全屏/操作页面时暂停。模拟输入被打断后会取消本次提交。 |
| 定时 | 支持每天、工作日、周末；浏览器运行时由后台闹钟启动。错过时间后可按设置补做今天或先询问。关机、休眠时无法执行。 |
| 每日活动 | 按页面识别任务，安全目标只处理可自动完成的探索活动；测验和投票可交给用户处理。微软改版后可能需要人工操作。 |
| 移动搜索 | 默认关闭。开启后仅对指定标签页设置手机请求头；这不保证微软认可为移动搜索，也不保证加分。 |
| 词库 | 支持本地词包、自定义词、换一批和拉黑。设置及词库可备份、导入。 |
| 记录 | Popup 展示近 7 天详情，设置页展示近 30 天；日志可按日期查看并导出。昨天未完成时可提醒，昨天积分无法补记。 |
| 连续不加分 | 沿用原有策略：达到阈值后按搜索已满结束本次任务。这是本机推断，也可能由限流或积分延迟造成；请以 Rewards 页面为准。 |

自动搜索和自动点击可能不符合 Microsoft Rewards 使用规则，存在积分无效或账号受限的风险，请自行判断是否使用。扩展不保证获得积分。

## 3.4.3 修复了哪些不好用的地方

| 已确认的问题 | 修复 |
| --- | --- |
| 首次点击开始也进入“继续搜索”模式，绕过目标次数 | 仅当天已完成后的主动重启允许越过目标 |
| 输入中被打断，备用路径仍可能点击搜索 | 中断、暂停、停止后取消提交 |
| 搜索点击后才保存标记，页面销毁时可能丢失；URL 跳转也未算提交成功 | 导航前等待标记落盘，统一点击与 URL 跳转 |
| Bing 页自带定时分支绕过补做开关和询问 | 所有页面定时检查统一由后台处理 |
| 完成当天任务后还提示补做，或电脑已满时遗漏移动阶段 | 补做前检查当天状态，启动判断包含移动阶段 |
| 漏做提醒开关存在，后台实现却直接返回 | 恢复每日最多一次的信息提醒，不自动补昨天 |
| 昨天的失败、小结和积分出现在今天；空积分被转成零 | 小结按日期过滤，缺失积分保持未知 |
| 后台异常不回复、保存失败仍显示成功 | 返回明确失败结果，设置页显示保存错误 |
| 月度积分图只有今天加分才显示 | 有历史加分就显示 |

详细记录见 [CHANGELOG.md](CHANGELOG.md)。

## 开发与验证

要求 Node.js 24。

```sh
npm ci
npm run lint
npm test
```

真实浏览器回归使用独立临时配置和本地拦截的 Bing 页面，不使用个人账号，也不向真实 Bing 发起搜索：

```sh
npx playwright install chromium
npm run test:browser
```

Windows 使用本机 Edge：

```powershell
$env:EDGE_EXECUTABLE = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
npm run test:browser
```

测试覆盖共享逻辑、开始/暂停/继续/停止、导航前保存、补做策略，以及实际加载扩展后的首次确认、设置、定时记忆、词库、搜索计分和完成。测试页面用于验证扩展行为，不能证明当前微软页面的所有布局和地区规则都兼容；账号真实积分和商店审核仍需现场确认。

GitHub Actions 执行 lint、JavaScript 测试和浏览器回归。

## 权限与隐私

- `alarms`：后台定时。
- `storage`：本机设置、词库、进度及日志。
- `tabs`：打开和管理 Bing 搜索、Rewards 标签页。
- `notifications`：完成、失败及漏做提醒。
- `declarativeNetRequestWithHostAccess`：仅在启用移动搜索时修改指定标签页的请求头。
- `https://*.bing.com/*`：在搜索和 Rewards 页面读取进度并执行用户启用的操作。

扩展设置和记录保存在本机，不上传到项目服务器。搜索会按正常浏览器行为发送给 Bing。详见 [PRIVACY.md](PRIVACY.md)。
